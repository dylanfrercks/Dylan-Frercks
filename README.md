# To-Do List

A simple, lightweight to-do list web app built with plain HTML, CSS, and JavaScript.

## Features

- Add tasks (click **Add** or press **Enter**)
- Mark tasks as complete
- Delete individual tasks
- Filter by All / Active / Done
- Clear all completed tasks at once
- Tasks persist via `localStorage` — survives page refreshes

## Usage

Just open `index.html` in any browser. No build step or dependencies required.
